## 下载与安装

1. 在本仓库 Releases 下载 `zhuodazi-android-encrypted.zip`。
2. 使用支持 AES 加密 ZIP 的解压工具，输入邀请者提供的密码，解压出 APK。
3. 点开 APK 并按手机提示安装。需要 Android 8 及以上的 64 位设备；iPhone 不能安装此 APK。
4. 联网时两端连接同一 Wi-Fi，iPhone 选择“苹果＋安卓通用”；保持 App 在前台。

密码不在公开页面提供，请向分享者获取。压缩包可以公开下载，获得密码的人可以解压并转发；应用本身没有邀请码或激活限制。
