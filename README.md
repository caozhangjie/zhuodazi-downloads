## 下载与安装

1. 下载 `zhuodazi-android-1.3.0-build25-encrypted.zip`。
2. 使用支持 AES 加密 ZIP 的工具，输入分享者提供的原密码，解压 APK。
3. 点开 APK 安装。支持 Android 8 及以上 64 位设备，原公开版可直接覆盖升级。
4. 面对面联机时，两端连接同一 Wi-Fi；iPhone 选择“苹果＋安卓通用”，保持 App 在前台。
