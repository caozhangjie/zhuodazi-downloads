1. 下载 `zhuodazi-android-1.4.40-build94-encrypted.zip`。
2. 使用支持 AES 加密 ZIP 的工具，输入分享者提供的原密码，解压 APK。
3. 点开 APK 安装。支持 Android 8 及以上64位设备，原公开版可直接覆盖升级。
